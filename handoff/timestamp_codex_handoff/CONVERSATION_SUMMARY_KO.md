# 대화 요약 — 타임스탬프 디자인 재현

## 사용자가 하려는 일

iOS 타임스탬프 앱으로 저장한 사진과 같은 디자인의 템플릿을 만들고 싶다. 특히 오른쪽 위의 `TIME STAMP` 로고와 왼쪽 아래의 한국어 날짜·시간을 가급적 정확하게 재현하고 싶다. **날짜와 시간은 사용자가 임의로 바꿀 수 있어야 한다.** 실제 구현은 별도의 Codex 환경에서 진행할 것이므로, 이 대화와 추출 자료를 인계해 달라고 요청했다.

플랫폼, 언어, 프레임워크, 저장 방식은 아직 선택되지 않았다. ChatGPT가 웹페이지 형태를 제안했지만 승인되거나 확정된 것은 아니다.

## 앱과 API 조사

- 사용자는 Apple App Store의 '타임스탬프' 앱이라고 설명했다.
- 사진 속 로고와 공식 정보를 근거로 Artify Inc.의 '타임스탬프 - 인증샷 카메라'(App Store ID 1115974495)로 추정했다. 사용자에게 개발사/앱 ID를 별도로 확인받은 것은 아니다.
- 공식 사이트와 앱 설명을 조사한 범위에서 공개 템플릿 API·SDK·템플릿 파일 다운로드 문서는 찾지 못했다. 'API가 절대 없다'고 확정한 것은 아니다.
- 공식 사이트에서 1024 × 1024 RGBA 시계·소인 아이콘을 찾았다. 하지만 TIME STAMP 영문 글자는 포함되지 않는다.
- 이후 사용자가 제공한 검정 샘플에서 영문 글자까지 포함한 전체 로고를 추출하는 경로를 택했다.

확인했던 링크:

- https://apps.apple.com/kr/app/id1115974495
- https://timestamp.camera/ko/
- https://timestamp.camera/images/logo.png

외부 서비스의 현재 API 제공 여부는 별도로 재확인이 필요할 수 있다. 이 패키지의 추출 작업은 API를 사용하지 않는다.

## 디자인 재현에 관해 논의한 내용

1. 동일한 원본 폰트와 렌더링 설정을 찾으면 문자열을 직접 그릴 수 있다. 폰트는 아직 식별하지 못했다.
2. 원본 앱의 출력에서 글자를 이미지로 분리해 조합하는 방법도 가능하다. 글자 모양뿐 아니라 간격·기준선·소수 픽셀 위치까지 맞춰야 한다.
3. 로고는 하나의 이미지로, 날짜·시간은 교체 가능한 글자/토큰으로 구성하는 방식을 제안했다.
4. 사용자는 검정 배경에 같은 디자인의 스탬프를 적용한 샘플을 제공했다.
5. 처음 추가한 7장은 1080 × 1080이었다. 이에 고해상도 원본을 요청했고, 최종적으로 3240 × 3240 샘플 7장을 다시 제공받았다.
6. 기존 월요일 검정 샘플을 더해, 최종 추출 입력은 3240 × 3240 JPEG 8장이다.
7. 그림자와 알파를 더 잘 알아내기 위해 흰 배경 보완 샘플도 제안했지만, 사용자가 만들기 어렵다고 하여 제공되지 않았다. 검정 샘플로 진행하기로 했다.

## 현재 상태

샘플 수집과 데이터 추출을 완료한 인계용 자료다. 대표 글자 PNG, 같은 글자의 여러 출현본, 요일·오전/오후 토큰, 로고, 전체 줄 이미지, 고정 오버레이, 좌표 JSON과 재추출 코드를 포함한다.

아직 하지 않은 작업은 원본 폰트 식별, 임의 문자열의 advance/kerning/기준선 복원, 동적 렌더러, 앱 UI, 밝은 배경 검증이다. '완벽히 동일하다'는 주장을 하지 말고, 측정된 사실과 남은 오차를 구분해야 한다.
