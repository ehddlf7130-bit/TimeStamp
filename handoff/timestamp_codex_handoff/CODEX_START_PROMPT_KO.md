이 폴더는 iOS 타임스탬프 사진 디자인을 재현하기 위한 인계 패키지입니다.

먼저 아래 파일을 읽어 주세요.

1. README_KO.md
2. CONVERSATION_SUMMARY_KO.md
3. CODEX_HANDOFF_KO.md
4. metadata/manifest.json 및 metadata/occurrences.json
5. metadata/validation.json

목표는 사진에 원본과 같은 형태의 로고와 한국어 날짜·시간을 넣되, 날짜와 시간은 사용자가 임의로 설정할 수 있게 만드는 것입니다. 플랫폼은 아직 정하지 않았으므로 기존 프로젝트가 있다면 그것을 먼저 조사하고, 없으면 렌더링 핵심과 플랫폼 선택을 구분해 진행해 주세요.

assets/canonical에는 날짜용/시간용 글자, 오전·오후 토큰과 괄호가 포함된 요일 토큰이 있고 assets/logo.png에는 영문 글자까지 포함한 전체 로고가 있습니다. 글자별 실제 출현본과 원본 좌표도 제공되어 있습니다. 원본 폰트와 정확한 advance/kerning/기준선은 아직 식별하지 못했습니다. PNG의 폭을 글자 진행 폭으로 단순히 사용하지 마세요.

먼저 python scripts/verify_assets.py로 현재 자료를 검증하고, 출현별 자산을 원래 좌표에 재조립해 기준 이미지를 확인해 주세요. 이후 글자 간격과 기준선을 분석하여 임의의 날짜를 렌더링하는 모듈을 구현해 주세요. 샘플의 날짜를 그대로 복사하는 것과 새로운 날짜를 조합하는 것은 구분하여 검증해야 합니다.

검정 배경으로부터 추정한 알파이며 원본 알파가 아닙니다. 검정 그림자, 밝은 배경 외관, 픽셀 단위 동일성은 아직 검증되지 않았습니다. 이를 보장한다고 말하지 마세요. 현재 자료로 먼저 진행하고 실제 한계가 확인될 때만 추가 자료를 요청해 주세요.

필요한 결과는 재사용 가능한 날짜·시간 포맷터와 합성 렌더러, 샘플별 비교 결과입니다. UI와 플랫폼은 현재 프로젝트 상황을 확인한 뒤 결정해 주세요.
